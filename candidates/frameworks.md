## f04 — 恐惧诉求两步法

```yaml
id: f04
title: 恐惧诉求两步法（痛苦场景+严重后果）
type: framework
source_chapter: "1.2 恐惧诉求"
source_quote: |
  恐惧诉求=痛苦场景（具体、清晰）+严重后果（难以承受）。
summary: |
  一种利用恐惧心理激发购买欲的结构化写作框架，由两个必要组件构成。
  第一步"痛苦场景"：指出一个具体的、读者能代入的痛苦情境，越具体越能引起共鸣。
  第二步"严重后果"：指出这个痛苦如果不解决，会带来难以承受的后果，迫使读者寻找解决方案。
  关键约束：痛苦场景必须具体而非抽象（不说"不读书没前途"，而说"高人谈笑风生你却无话可讲"），
  严重后果必须难以承受而非轻微不便。适用于省事型、预防型和治疗型产品。
tags: [恐惧诉求, 痛点挖掘, 心理动机, 说服框架]
```

## f08 — 顾客证言精选法（核心需求击中框架）

```yaml
id: f08
title: 顾客证言精选法（核心需求击中框架）
type: framework
source_chapter: "1.6 顾客证言"
source_quote: |
  挑选的证言，必须能击中顾客的核心需求。核心需求，是指顾客花钱最想满足的需求，不满足他干脆不会买。
summary: |
  一种利用从众心理选择顾客评价的决策框架。核心操作不是"收集好评"，而是"精选击中核心需求的证言"。

  但可以用顾客证言间接表达效果。
```

## f09 — 权威转嫁两步法

```yaml
id: f09
title: 权威转嫁两步法（高地位+高标准）
type: framework
source_chapter: "2.1 权威转嫁"
source_quote: |
  完整的"权威转嫁"要做两步：1.塑造权威的"高地位"：无论你借势哪个权威，你一定要展示它是非常专业的、高级别的、影响力很大的。2.描述权威的"高标准"：要求很高、很严苛，一般人无法获得，你得之不易！
summary: |
  一种将外部权威的信任光环嫁接到产品上的两步框架。
  第一步"高地位"：展示权威的专业性、级别和影响力，让读者知道这个权威在行业内举足轻重。
  第二步"高标准"：描述获得该权威认可的难度和稀缺性，让读者理解这个认可来之不易。
  两步缺一不可：只说高地位不提高标准，读者会觉得"随便就能拿到"；
  只说高标准不提高地位，读者不知道这个权威有多重要。
  权威来源包括：权威奖项、权威认证、权威合作单位、权威大客户、明星顾客、团队专家等。
  找不到直接权威时，可以描述哪些权威认同你的产品理念，间接支撑品质。
tags: [权威背书, 信任转嫁, 两步法, 社会证明]
```

## f13 — 算账说服法（平摊/省钱两条路径）

```yaml
id: f13
title: 算账说服法（平摊/省钱两条路径）
type: framework
source_chapter: "3.2 算账"
source_quote: |
  平摊：当产品很耐用，但价格比较高时，我们可以把价格除以使用天数，算出一天多少钱。省钱：如果产品能节水、节电或替代其他消费，我们帮他算出每年，或是10年能帮他省多少钱。
summary: |
  一种帮读者在付款前完成"价值>价格"判断的计算框架。包含两条路径：
  路径一"平摊"：将总价除以使用天数/人数，算出每天/每人多少钱，使大数字变小。
  路径二"省钱"：计算产品能替代的已有消费或节省的长期费用，让读者发现"很快回本"。
  进阶技巧：先扣除已有支出再算增量（如生态米总价减去普通米费用后再算每月多花多少），
  使结果更小更有说服力。
  核心洞察：读者付款时心中有一架天平，一边是价值一边是价格，与其让他"胡思乱想"不如帮他算清这笔账。
tags: [价值框架, 计算说服, 价格心理, 决策辅助]
```

## f15 — 限时限量促单法（三种形式）

```yaml
id: f15
title: 限时限量促单法（时间/数量/身份限制）
type: framework
source_chapter: "3.4 限时限量"
source_quote: |
  引导马上下单之"限时限量"：告诉读者现在的优惠是限时限量的，如果错过，产品会涨价，甚至售罄买不到，迫使他马上做出决定。常见的形式有这3种：限时（设置截止时间）、限量（设置名额上限）、限身份（设置享受优惠的身份门槛）。
summary: |
  一种利用稀缺性原理迫使读者立即行动的促单框架。包含三种形式：
  限时：设置精确到月/日/时/分的截止日期，越具体越可信。
  限量：先说明总量有限，再告知已被预订多少、所剩更少，叠加"畅销"暗示。
  限身份：设置享受优惠的身份门槛（如60岁以上），让符合条件的人产生"庆幸感"，
  感觉机会难得。
  核心原理：人们在掏钱时会犹豫拖延，告诉他"不马上行动就会吃亏"可以打破拖延。
  关键约束：稀缺信号必须具体可信，模糊的"限时"会被忽略。
```
