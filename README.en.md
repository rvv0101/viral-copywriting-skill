# Viral Copywriting Skill

A ready-to-use AI skill toolkit that distills Guan Jianming's *Bao Kuan Wen An* into 14 modular writing and diagnosis tools for conversion-focused copywriting.

This is not a book summary page. The book is the source of these skills, not the main character of this page.

## What Problems Do These Skills Solve

- Writing sales copy for product pages, WeChat posts, ads, or community commerce from scratch
- Diagnosing why existing copy gets traffic but fails to convert
- Turning raw product features into concrete desire, trust, and urgency
- Building authority, evidence, testimonials, and price justification into a copy flow
- Turning conversion copywriting into reusable agent workflows

## What Was Distilled

14 triple-verified skills extracted from *Bao Kuan Wen An*, organized around a four-step sales funnel: attention-grabbing title -> purchase desire -> reader trust -> immediate action.

### Meta Framework

- `copywriting-four-step-system`: The overall structure and diagnostic framework that coordinates the other skills

### Create Purchase Desire

- `sensory-occupation`: Use sensory writing so readers can mentally try the product
- `fear-appeal`: Use painful scenarios plus serious consequences to create urgency
- `cognitive-contrast`: Contrast competitor weakness with your advantage
- `usage-scenario`: Design concrete usage scenes for lazy readers
- `customer-testimonial`: Select testimonials that hit the buyer's core need

### Build Trust

- `authority-transfer`: Transfer trust through authority status and authority standards
- `factual-evidence`: Translate technical data into familiar facts or visible experiments

### Drive Immediate Action

- `price-anchor`: Use high-price reference points to reshape price perception
- `cost-accounting`: Break price into daily cost or long-term savings
- `justified-consumption`: Reframe buying as self-improvement, gifting, health, or care for children

### Title Writing

- `news-editorial-title`: News subject + immediacy words + major-news language
- `friend-chat-title`: "You" + conversational phrasing + exclamation
- `practical-tip-title`: Specific pain + perfect outcome or practical fix

## Effect Examples

### Example 1: Diagnose Non-Converting Copy

**User Question**

> "This product page gets traffic, but very few people buy. Can you diagnose it?"

**Skill Judgment**

- Trigger `copywriting-four-step-system` to inspect title, desire, trust, and action
- If the copy only lists features, use `sensory-occupation` or `cognitive-contrast`
- If readers do not trust the claim, use `authority-transfer`, `factual-evidence`, or `customer-testimonial`
- If the product feels expensive, use `price-anchor`, `cost-accounting`, or `justified-consumption`

**Response Example**

> The issue is not a lack of information. Desire and trust are not alternating. The first half lists specs, so readers never see themselves using the product. The ending suddenly gives a discount without proving why the product is worth buying now. Restructure it as 1-232-34: a concrete pain-point title, a vivid usage scene, factual proof, then price anchoring and cost accounting at the close.

## How These Skills Were Generated

These skills were generated using the **cangjie-skill** RIA-TV++ pipeline, a six-stage process:

1. **Whole-Book Understanding (Adler Analysis)** — Apply Mortimer Adler's analytical reading method to produce `BOOK_OVERVIEW.md`
2. **Parallel Extraction** — Use five extractors for frameworks, principles, cases, counterexamples, and terminology
3. **Triple-Verification Screening** — Require cross-domain evidence, predictive power, and non-obviousness
4. **RIA++ Construction** — Structure each skill across Reading, Interpretation, Past Application, Future Trigger, Execution, and Boundary
5. **Zettelkasten Linking** — Identify dependencies, contrasts, and compositions between skills
6. **Stress Testing** — Create test prompts with decoys for each skill
